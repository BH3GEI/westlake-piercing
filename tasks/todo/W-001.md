## 1. 墙签名 (wall signature)
uptodown `AppCompatActivity` → `setContentView` → `createSubDecor` 需要 Theme.AppCompat 的 `windowActionBar`。
app 主题 `AppThemeBar(0x7f15000e)` parent chain：
`AppThemeBar → Theme.AppCompat.DayNight.NoActionBar → Platform.V21.AppCompat.Light → @android:style/Theme.Material.Light.NoActionBar(0x01030241)`。
跨包跳到 framework package `0x01` 时，若 AssetManager 的 `BuildDynamicRefTable` 里 **没有 package 0x01**，`GetBag` 空 → `hasWab=false` / `uamHasWab=false`。
症状符号化：`uamHasWab=false`（或等价：`obtainStyledAttributes(AppCompatTheme)` 后 `windowActionBar`/`colorPrimary`/`windowContentOverlay` 全无值）。
