七、口径 · 方法学 · 可信度

  • 判据：方法运行时是否必须向下调 OH 原生/系统能力（非"系统 vs 应用"）。getter 即使数据源自 OH，本身仍是 java_synth(不桥接)。
  • 流程：确定性分类器 selected_bridge() 出种子 → codex(gpt-5.5) 并发逐方法分类+难度精修 → 算术/wifi 校验。347 包 0 失败。
  • 版本：AOSP 15 × OH 6.1.0.31（libc/native 取 RK3568/D200 实机）。
  • 三重交叉验证：算术闭合 ✓；wifi 58 vs 人工真值 66(88%) ✓；libc 交集 1,203 ≈ 旧估 1,160 ✓；HanBing 实测 2,415 方向一致。
  • 已知边界：@hide 灰名单(数十万内部成员)未计；构造函数/字段/枚举未计入 method 数；加密 host 构建符号偏高估需按 APK 收紧；不同单位(method vs symbol)分列不相加。
  • APK 内嵌 .so：属 L4 app-gap native，按目标 APK 实际 import 的符号 ∩ 桥接集计；红线(跨 allocator)那批最危险，须 bionic 命名空间隔离。
